# DB Demo — CRUD Operations

## Overview

A simple web app that demonstrates database CRUD operations using Flask and a JSON file.

## Tech Stack

- **Frontend**: HTML + CSS + JavaScript
- **Backend**: Flask (Python)
- **Database**: JSON file

## Requirements

### Create
- Add a new record via a form or API call

### Read
- Display all records in a table
- Optionally view a single record in detail

### Update
- Edit an existing record and save the changes

### Delete
- Remove a record from the list

## UI
- Clean, modern design
- Responsive layout
- Table view for data
- A modal or panel to preview raw JSON data

## Deployment
- Bind to `0.0.0.0` so other devices on the same WiFi can access it
