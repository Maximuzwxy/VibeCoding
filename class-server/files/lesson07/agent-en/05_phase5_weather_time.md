# Phase 5 — Add Time, Location & Weather

## Goal
Enable the AI to access real-time information

## Features
- `get_current_time` — Get the current time
- `get_location` — Get location info (city)
- `get_weather` — Get weather information

## Use Cases
```
User: What's the weather today?
Agent: [calls get_location] → [calls get_weather] → Beijing is sunny today, 28°C
```
