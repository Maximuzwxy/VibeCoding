# Phase 5 — Admin Dashboard

## Goal
Implement an admin backend for managing users and posts.

## Requirements

### Admin Login
- Username/password login
- Default account: `admin` / `111111`

### Dashboard

**Statistics:**
- Total users, total posts, monthly active users, today's active users

**User Management:**
- List all users: avatar, username, registration date, friend count, post count
- View user details

**Post Management:**
- List all posts: author, content, likes, comments, time
- View post detail with comments
- Delete inappropriate posts
