# Phase 7 — Earth + Moon + Cloud Layer

## Goal
Implement Earth, validating the framework's support for satellite systems and child-object cloud layers.

## Requirements

### Earth Specifics
- Blue ocean and green continent surface texture
- Polar ice caps (north and south)
- Sahara desert, Himalayas, and other geographic features visible
- Axial tilt: 23.44°

### Moon
- One satellite orbiting Earth
- Grey textured surface
- Own orbit and rotation

### Cloud Layer
- Semi-transparent cloud texture as a child object of Earth
- Clouds follow Earth's rotation and axial tilt
