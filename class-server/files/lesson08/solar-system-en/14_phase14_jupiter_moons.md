# Phase 14 — Jupiter's Galilean Moons (4)

## Goal
Implement close-up textures for Jupiter's four Galilean moons.

## Requirements

### Four Moons

| Moon | Visual Features | Color |
|------|----------------|-------|
| **Io** | Sulfur yellow + orange deposits + red volcanoes + dark calderas + white plumes | Yellow-orange |
| **Europa** | Ice white base + dark ice cracks + parallel ridges + bright/dark regions | Ice blue |
| **Ganymede** | Grey-brown ice-rock mix + dark ancient regions + bright grooves + craters | Grey |
| **Callisto** | Grey-brown ancient surface + multi-ring Valhalla structure + dense craters | Brown-grey |

- Each moon has its own detailed, procedurally generated texture
- Close-up viewing mode available from the moon selector
