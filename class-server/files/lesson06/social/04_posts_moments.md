# Phase 4 — Posts (Moments / Friend Circle)

## Goal
Implement post publishing, browsing, and interactions (likes and comments).

## Requirements

### Publishing Posts
- Text content (max 500 characters)
- Optional images (max 9 per post)
- New posts appear at top of feed

### Post Feed
- Shows posts from friends and self, sorted newest first
- Each post: avatar, username, text, images, time
- Click image to view full size
- Like button with count and user list
- Comment section with input

### Likes
- Tap to like, tap again to unlike
- Show usernames who liked

### Comments
- Add comment below any post
- Show commenter avatar, name, content, time
- Delete own comments

### User Profile
- Show avatar, username, bio, and all posts
- Non-friends: browse only, no interaction
