# Phase 3 — Instant Messaging (WebSocket)

## Goal
Implement real-time chat between friends using WebSocket.

## Requirements

### Session List
- Show all chat conversations with friend avatar, name, last message, time
- Unread messages: red dot indicator

### Chat Detail
- Top bar: back button, friend name, avatar
- Messages: sent (right), received (left), bubble style
- Input box + send button at bottom, Enter to send
- Auto-scroll to bottom on new message

### Real-time Messaging
- WebSocket for instant delivery
- Only allow messaging between friends
- Load chat history when opening a conversation
- Mark as read when viewing the chat
