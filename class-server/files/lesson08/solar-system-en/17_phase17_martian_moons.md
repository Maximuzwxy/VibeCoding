# Phase 17 — Martian Moons (Phobos & Deimos)

## Goal
Complete solar system moon coverage with close-up textures for Mars's two moons.

## Requirements

### Two Moons

| Moon | Visual Features | Color |
|------|----------------|-------|
| **Phobos** | Grey-brown irregular body + Stickney crater (~1/3 diameter) + dense grooves + rough surface | `#8b7355` |
| **Deimos** | Grey-brown smooth surface + fewer craters + fine grain texture | `#a0826d` |

- Both are small, irregularly shaped asteroid-type moons
- Phobos has a prominent large crater and surface grooves
- Deimos is smoother with fewer impact features
