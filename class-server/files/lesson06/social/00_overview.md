# Social Network App — Overview

## Goal
A simple social networking web app with user accounts, friend management, instant messaging, and post sharing.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML + CSS + JavaScript |
| Backend | Flask (Python) |
| Real-time | WebSocket (SocketIO) |
| Database | JSON files |

## UI Style Selection

Before development, choose one UI style. All pages must follow the chosen style.

| # | Style | Description |
|---|-------|-------------|
| UI-1 | Modern Minimalist | Clean, subtle shadows, neat cards |
| UI-2 | Glassmorphism | Frosted glass effect, gradient background |
| UI-3 | Dark Mode | Deep dark theme, neon accents |
| UI-4 | Flat Design | No shadows, solid colors |
| UI-5 | Gradient Colorful | Rainbow gradients, rich animations |
| UI-6 | Vintage | Serif fonts, warm tones, paper texture |
