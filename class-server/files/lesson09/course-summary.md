# Vibe Coding 课程总结

## Lesson 01 — 入门：AI 驱动的编程

- Vibe Coding 核心理念：用自然语言描述意图，AI 生成代码
- Trae IDE 介绍：界面布局、AI Chat Panel 使用方法
- AI 模型配置（DeepSeek API Key）
- HTML / CSS / JavaScript 三件套基础概念
- 浏览器 DevTools Console 基础调试
- **课堂练习**：《小王子》段落变色页面

---

## Lesson 02 — 代码、文档、记忆与游戏

- HTML/CSS/JS 三文件分离规范（Separation of Concerns）
- Trae IDE 项目规则（Project Memory / Rules）配置
- Markdown 文档基础
- Git 版本控制基础概念
- **项目**：Pong 双人弹球游戏（含 AI 对手、Buff 道具系统、设置面板）

---

## Lesson 03 — 3D 世界，由你构建

- 3D 基础概念：场景、网格、坐标系、相机
- Three.js 库入门
- OrbitControls 轨道旋转控制
- FPS 第一人称控制（WASD 移动、鼠标视角、碰撞检测）
- **项目**：3D 场景编辑器（创建/选择/编辑物体，Orbit/FPS 模式切换）

---

## Lesson 04 — 用精确的语言描述 3D

- 向 AI 描述 3D 场景的精确表达技巧
- 将 2D 游戏概念转化为 3D
- Web Audio API 程序化音效
- **项目**：3D Pong 游戏（3D 球体物理、AI 对手、Buff 系统、粒子特效、音效）

---

## Lesson 05 — 前端 + 后端 + 数据库

- Flask 后端框架入门
- 三层架构：前端（浏览器）+ 后端（Flask）+ 数据库（JSON）
- RESTful API 设计：GET/POST/PUT/DELETE
- CRUD 增删改查操作
- `host='0.0.0.0'` 局域网访问
- **项目**：飞机射击游戏（用户登录、排行榜持久化、前后端数据交互）

---

## Lesson 06 — 社交网络

- 复杂应用的功能拆解与分阶段实现
- 用户认证（注册、登录）
- WebSocket 实时通信
- 好友关系管理、即时聊天
- **项目**：社交网络（登录注册、好友系统、即时通讯、朋友圈、管理后台）

---

## Lesson 07 — 接入大模型，打造 AI Agent

- LLM（大语言模型）与 Agent 的区别
- API Key 概念与安全
- Token 计费机制
- 对话历史记忆实现
- Function Calling（工具调用）
- **项目**：AI Agent（多轮对话、记忆系统、文件操作、语音输入、天气/时间/搜索工具）

---

## Lesson 08 — 太阳系探索平台

- 可复用框架设计：一个 CelestialSystem，配置出所有天体
- LLM 作为研究助手：生成结构化数据和 Quiz 题目
- 多语言支持（中英文切换）
- 前端（Three.js）+ 后端（Flask）+ 数据库（JSON）+ AI（DeepSeek）全栈整合
- **项目**：3D 太阳系（8 大行星 + 月球 + 天宫空间站、InfoPanel、Quiz、AI 聊天）

---

## Lesson 09 — 打造你自己的项目

- 想法梳理：先和 AI 沟通，形成需求文档
- 分阶段规划与迭代开发
- 利用 AI 调试和推进进度
- Presentation 制作：AI 生成 MD 文档 → 网页版 PPT 展示
- **项目**：学生自选项目 + 演示文稿展示
