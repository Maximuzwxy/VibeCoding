# Vibe Coding Course Syllabus

## Course Overview

This 10-session course is designed to guide students from zero programming experience to building complete AI-powered web applications. Through hands-on practice with fun mini-projects and games, students will learn to collaborate effectively with AI assistants to code, debug, and deploy creative applications.

---

## Session 1: Introduction to AI & Vibe Coding

**Topics:**
- What is AI and how it's transforming software development
- Introduction to Vibe Coding: programming with AI assistance
- HTML syntax basics: structure, tags, and elements
- Mini projects: interactive web pages and simple browser games
- Installing Trae

**Hands-on Practice:** Create your first web page with AI assistance

---

## Session 2: AI-Assisted Debugging & Classic 2D Game Development

**Topics:**
- How to collaborate with AI to find and fix bugs
- Effective prompt engineering for debugging
- Reading error messages and AI response interpretation
- Iterative development workflow with AI

**Hands-on Practice:** Build the classic 2D Pong game with AI guidance

---

## Session 3: Web Architecture, Version Control & 3D Basics

**Topics:**
- Web page structure: separating HTML, CSS, and JavaScript
- The role of each technology in modern web development
- Introduction to version control and its importance
- Git basics: init, add, commit, push, and branching
- Trae version management: reverting to previous versions in chat interface
- Introduction to 3D graphics on the web
- Three.js fundamentals: scenes, cameras, geometries, and materials
- Lighting, textures, and animations
- 3D Demo: interactive teaching demonstration

**Hands-on Practice:** Build a mini application with Git/Trae workflows, explore 3D with a Three.js teaching demo

---

## Session 4: 3D Game Development

**Topics:**
- Building interactive 3D games
- 2D Pong → 3D Pong game transformation
- FPS game development

**Hands-on Practice:** Transform 2D Pong into 3D Pong, and build an FPS game

---

## Session 5: Full-Stack Development & Airplane Battle Game

**Topics:**
- Understanding web architecture: frontend, server, and database
- Introduction to Flask (Python web framework)
- Working with JSON databases
- Database basics and DB demo
- RESTful APIs: concepts and implementation
- Writing structured requirement documents in Markdown format

**Hands-on Practice:** Build an airplane battle game with ranking system, using database to store user data and rankings

---

## Session 6: Social Application Development

**Topics:**
- Building complex interactive applications
- Real-time communication concepts
- User interface design for social platforms

**Hands-on Practice:** Build a social app (like WeChat)

---

## Session 7: AI Agent Development

**Topics:**
- Introduction to LLM APIs
- How AI Agents work: principles and architecture
- Building conversational AI interfaces

**Hands-on Practice:** Build an AI Agent

---

## Session 8: Solar System Project

**Topics:**
- Building interactive knowledge systems
- Integrating multiple technologies: HTML + Flask + Database + LLM API

**Hands-on Practice:** Build a Solar system project

---

## Session 9: Final Project Development (Part 1)

**Topics:**
- Independent project implementation
- One-on-one AI-assisted development support
- Problem-solving and debugging strategies
- Code review and optimization

**Hands-on Practice:** Work on your personal final project with AI and instructor support

---

## Session 10: Project Completion & Course Wrap-up

**Topics:**
- Final project presentations and demonstrations
- Code review and feedback session
- Course summary and key learnings
- Next steps in your coding journey

**Hands-on Practice:** 
- Complete and present your final project
- Celebrate your achievements!

---

## Learning Outcomes

By the end of this course, students will be able to:

✅ Understand AI's role in modern software development  
✅ Build interactive web pages and games using HTML, CSS, and JavaScript  
✅ Create 3D web experiences with Three.js  
✅ Develop full-stack applications with Flask and databases  
✅ Integrate LLM APIs to build AI-powered applications  
✅ Use Git and Trae for version control and collaborative development  
✅ Effectively collaborate with AI coding assistants  
✅ Plan, design, and implement complete web applications independently  

---

## Prerequisites

- No prior programming experience required
- A computer with internet access
- Enthusiasm to learn and experiment!

---

## Tools & Technologies

- **Code Editor:** Trae
- **Frontend:** HTML5, CSS3, JavaScript
- **3D Graphics:** Three.js
- **Backend:** Python, Flask
- **Database:** JSON-based storage
- **AI Integration:** LLM APIs
- **Version Control:** Git & GitHub

---

*Course Duration: 10 sessions*  
*Teaching Approach: Project-based learning with AI-assisted development*
