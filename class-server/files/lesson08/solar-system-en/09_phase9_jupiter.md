# Phase 9 — Jupiter + Gas Giant + Galilean Moons

## Goal
Implement Jupiter, validating support for gas giants and multi-satellite systems.

## Requirements

### Jupiter Specifics
- Brown-beige striped surface texture with atmospheric bands
- Great Red Spot (iconic storm feature)
- Cloud layer and storm vortex details
- Very fast rotation (10-hour day)
- Axial tilt: 3.13°

### Galilean Moons (4)
- **Io**: yellowish (volcanic surface)
- **Europa**: pale blue (icy crust)
- **Ganymede**: grey (largest moon in the solar system)
- **Callisto**: brown-grey (ancient cratered surface)
- Orbital speeds decrease with distance (inner moons faster)
