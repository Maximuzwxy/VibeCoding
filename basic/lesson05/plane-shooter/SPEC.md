# Plane Shooter - 飞机射击游戏

## 项目概述

**类型**: 2D 竖版射击游戏

**核心玩法**: 玩家控制战斗机，击败敌人波次，挑战 BOSS，通关 6 个关卡

**目标用户**: 休闲玩家，支持单人/双人本地联机

---

## 技术栈

| 组件 | 技术 |
|------|------|
| 后端 | Python Flask |
| 前端 | HTML5 Canvas + 原生 JavaScript |
| 渲染 | Canvas 2D API（无图片文件） |
| 音频 | Web Audio API（无音频文件） |
| 数据存储 | JSON 文件 |
| 网络访问 | 支持局域网访问（手机/电脑同 WiFi 即可访问） |

## 阶段一：基础游戏功能

### 目标
实现可运行的飞机射击游戏核心玩法，无需登录即可游玩。

### 游戏画面
- Canvas 尺寸：800 x 600 像素
- 游戏状态：MENU、PLAYING、GAME_OVER、LEVEL_COMPLETE
- 星空背景动画

### 玩家系统
| 操作 | 玩家 1 | 玩家 2 |
|------|--------|--------|
| 上移 | ↑ | W |
| 下移 | ↓ | S |
| 左移 | ← | A |
| 右移 | → | D |
| 射击 | Space | F |

- 默认 3 条命
- 被击中后有短暂无敌时间

### 敌人系统
- 3 种敌机类型：小、中、大
- 敌机会随机发射子弹
- 敌机会左右移动并缓慢下降

### 波次系统
- 每关波数 = 2 + 关卡等级（3-8 波）
- 每波敌人数 = 3 + (波数 × 2)
- 击败所有波次后 BOSS 出现

### BOSS 系统
- 6 个关卡对应 6 个 BOSS
- BOSS 有 3 种攻击模式：单发、扩散、圆形
- 每 5 秒切换一次攻击模式

| 关卡 | BOSS 名称 |
|------|-----------|
| 1 | Rock Destroyer |
| 2 | Battle Cruiser |
| 3 | Mothership |
| 4 | Station Core |
| 5 | Storm Bringer |
| 6 | Final Boss |

### 道具系统
| 图标 | 类型 | 效果 | 持续时间 |
|------|------|------|----------|
| 🔥 | 快速射击 | 加快射速 | 10 秒 |
| 🛡️ | 护盾 | 无敌状态 | 8 秒 |
| ⭐ | 多重射击 | 同时发射 3 颗子弹 | 12 秒 |
| ❤️ | 额外生命 | +1 条命 | 永久 |
| 💣 | 炸弹 | 清除屏幕上所有敌人 | 立即 |

### HUD 显示
- 生命值
- 当前分数
- 当前波次/总波次
- 当前关卡
- 当前激活的道具

### 积分系统
- 击毁敌机：100-500 分（根据类型）
- 击败 BOSS：1000 分
- 通过波次：+100 分奖励
- 通关奖励：+1000 分

### 难度系统
| 难度 | 敌机速度 | 敌机血量 | 射击延迟 |
|------|----------|----------|----------|
| 简单 | 0.7x | 0.7x | 1.3x |
| 普通 | 1.0x | 1.0x | 1.0x |
| 困难 | 1.4x | 1.5x | 0.7x |

## 阶段二：音效与设置

### 目标
添加游戏音效、背景音乐和设置选项，提升游戏体验。

### 音效系统
使用 Web Audio API 生成所有音效，无需外部音频文件：

| 音效 | 描述 |
|------|------|
| 射击 | 短促蜂鸣 |
| 爆炸 | 噪声爆发 |
| 道具 | 上升音调 |
| BOSS 来袭 | 警报音 |
| 击中 | 低沉撞击 |
| 炸弹 | 轰鸣消退 |
| 通关 | 胜利旋律 |

### 背景音乐
- 程序生成的氛围音乐
- 使用正弦波振荡器

### 设置菜单
| 设置项 | 默认值 | 选项 |
|--------|--------|------|
| 生命数 | 3 | 1, 3, 5 |
| 音效 | 开 | 开/关 |
| 音乐 | 开 | 开/关 |
| 难度 | 普通 | 简单/普通/困难 |

## 阶段三：用户系统

### 目标
添加登录注册、分数保存、排行榜功能，实现玩家数据持久化。

### 登录系统
- 用户名登录（自动注册）
- 会话管理
- 登出功能

### 数据持久化
- 用户列表存储
- 分数记录存储（用户名、分数、关卡、时间）
- 每次游戏结束自动保存最高分

### 排行榜
- 显示前 10 名玩家
- 显示用户名、分数、关卡、通关时间
- 页面展示

### API 接口

| 方法 | 端点 | 描述 |
|------|------|------|
| GET | `/` | 首页（重定向到登录） |
| GET | `/login` | 登录页面 |
| POST | `/login` | 登录/注册 |
| GET | `/logout` | 登出 |
| GET | `/leaderboard` | 排行榜页面 |
| GET | `/rules` | 游戏规则页面 |
| POST | `/api/save_score` | 保存分数 |
| GET | `/api/get_user_best` | 获取用户最高分 |
| GET | `/api/leaderboard` | 获取排行榜数据 |

### 数据模型

```json
{
  "users": [
    {
      "id": 1,
      "username": "string",
      "created_at": "datetime"
    }
  ],
  "scores": [
    {
      "id": 1,
      "username": "string",
      "score": 15000,
      "level": 6,
      "date": "2024-01-10 15:30:00"
    }
  ]
}
```

## 部署需求

### 网络配置
- **绑定地址**: `0.0.0.0`（允许局域网内所有设备访问）
- **局域网访问**: 同一 WiFi 下可通过 `http://[电脑IP]:5000` 访问
- **本机访问**: `http://localhost:5000`

### 启动配置
```python
app.run(debug=True, host='0.0.0.0', port=5000)
```

### 注意事项
- 本配置仅适用于本地开发调试
- `debug=True` 模式下不应暴露给不受信任的网络
- 确保防火墙允许 5000 端口的入站连接

## 游戏规则

1. 使用方向键移动战斗机
2. 按空格键射击
3. 击败一波敌人后才能进入下一波
4. 击败 BOSS 才能通关当前关卡
5. 收集道具获得优势
6. 生命归零游戏结束
7. 游戏结束可保存分数到排行榜
