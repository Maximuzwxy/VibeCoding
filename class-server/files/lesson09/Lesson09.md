# Vibe Coding Project Checklist

## 📁 Project Setup

- Create a new folder named after your project
- Start a new AI conversation session
- Initialize Git repository and commit regularly

## 🛠️ Tech Stack

- **Frontend:** HTML + CSS + JavaScript (vanilla) + Three.js(Optional)
- **Backend:** Flask
- **Database:** JSON files

## 📋 Requirements

- Define `requirements.md` before coding
- For large projects, discuss implementation steps and version milestones with AI in `requirements.md`
- **Do not** let AI write all code at once

## 🔄 Development Workflow

- Complete one version → Test → Continue to next version
- If requirements change, update `requirements.md` immediately
- Use Git: commit code frequently after each working version

## 🔑 API Configuration

- Configure your API key securely (e.g., `config.py` or environment variable)

## ✅ Optional (Recommended)

- Ask AI to provide test plans and test code for each development stage

---

**💡 Tips:**
- Keep AI conversation history for reference
- When encountering bugs, provide error messages + relevant code to AI
- Let AI generate commit messages after each version
