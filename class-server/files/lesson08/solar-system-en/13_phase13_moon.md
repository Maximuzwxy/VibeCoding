# Phase 13 — Moon Framework + Earth's Moon (Textured)

## Goal
Validate the satellite texture system and implement Earth's Moon with its own detailed texture.

## Requirements

### Moon Framework
- CelestialSystem's `orbitingBodies` already supports `textureGenerator` for moons
- No framework changes needed — just configure textures
- Same CanvasTexture approach as planets

### Earth's Moon
- Grey cratered surface with mare (dark plains) and highlands
- Detailed crater texture with lighter and darker regions
- Close-up view mode available
