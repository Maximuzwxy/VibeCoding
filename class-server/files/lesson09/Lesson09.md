# Vibe Coding: Build Your Own Project

## 09 Build Your Own Project

The theme of today's class is completing your own project. The session is divided into three phases:

### Phase 1: Idea & Planning

Don't rush into writing code — chat with AI first. Tell AI what you want to build and let it help you:

- **Organize your ideas**: Turn the scattered thoughts in your head into a clear document (MD format) covering the project's theme, core features, target audience, etc.
- **Plan the stages**: Let AI break your project into smaller phases, defining what each phase should accomplish and which technologies you'll need.

> **Example prompt**:
> "I want to build a XX project. My rough idea is XXX. Please help me organize the requirements into an MD document first, then plan it out in a few phases for implementation."

### Phase 2: Build It

Follow the plan from Phase 1, implementing one stage at a time with AI's help. Test each stage in the browser before moving on to the next.

**Tips**:
- After completing each stage, ask AI to summarize your current progress and what's next
- Don't panic when you hit a bug — paste the error message to AI, and it will help you troubleshoot
- Review the concepts you've learned so far (Three.js, Flask, fetch, backend APIs, etc.) and see how they can apply to your project

### Phase 3: Create Your Presentation

At the end of class, everyone will have time to do a **presentation** to showcase their work.

Use AI to help with this too:

1. **Generate a Presentation MD document**: Review the concepts, assignments, and mini-projects you've worked on, and have AI organize them into a presentation outline
2. **Generate a web-based slideshow**: Give the MD document to AI and ask it to build a web-based presentation page with left/right slide navigation

> **Example prompt**:
> "Based on the MD content below, generate a web-based presentation page that supports left/right slide navigation, with a clean and elegant style. The content includes what I've learned, assignments I've completed, and my personal project."
