# DB Demo - 数据库 CRUD 操作示例

## 项目概述

一个简单的 Web 应用程序，演示数据库的 CRUD（增删改查）操作。

## 技术栈

- **前端**: HTML
- **后端**: Flask (Python)
- **数据存储**: JSON 文件（轻量级数据库）

## 功能需求

### 1. Create（创建）
- 添加新数据记录

### 2. Read（读取）
- 查看所有数据记录
- 查看单条数据记录详情

### 3. Update（更新）
- 修改现有数据记录

### 4. Delete（删除）
- 删除数据记录

## UI 设计需求

- **现代化风格**: 简洁、清爽的视觉效果
- **响应式布局**: 适配不同屏幕尺寸
- **表格展示**: 数据以表格形式清晰呈现
- **美观的表单**: 输入框、按钮样式统一
- **交互反馈**: 悬停效果、动画过渡
- **配色方案**: 使用柔和的渐变色系
- **JSON 查看器**: 模态框展示原始 JSON 数据

## 部署需求

### 网络访问配置
- **绑定地址**: `0.0.0.0`（允许局域网内所有设备访问）
- **访问方式**: 启动服务后，同一 WiFi 下的手机/电脑可通过 `http://[电脑IP]:5000` 访问
- **本地访问**: `http://localhost:5000` 或 `http://127.0.0.1:5000`

### 配置示例
```python
app.run(debug=True, port=5000, host='0.0.0.0')
```

### 注意事项
- **开发环境**: 此配置仅适用于本地开发调试
- **安全性**: `debug=True` 模式下不应暴露给不受信任的网络
- **防火墙**: 确保本地防火墙允许 5000 端口的入站连接
