## Get your API key
- Open website https://bailian.console.aliyun.com/cn-beijing/?tab=model#/api -key
- Click on the top right corner to log in, and use Alipay/Taobao APP to scan the code to complete the login
- Click the Create API Key button, select the account in the pop-up window, and click the Confirm button to generate the API Key. Click the Copy button to copy it
