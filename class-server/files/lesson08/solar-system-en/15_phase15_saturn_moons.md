# Phase 15 — Saturn's Moons (7)

## Goal
Implement close-up textures for Saturn's seven major moons.

## Requirements

### Seven Moons

| Moon | Visual Features | Color |
|------|----------------|-------|
| **Mimas** | Grey ice shell + Herschel crater (~1/3 diameter) + central peak | Grey |
| **Enceladus** | Bright white ice + tiger stripe fractures + very high reflectivity | White |
| **Tethys** | Light grey ice + craters | Light grey |
| **Dione** | Medium grey ice + bright spots | Mid grey |
| **Rhea** | Dark grey ice + craters | Dark grey |
| **Titan** | Orange-yellow thick atmosphere + methane lakes + dunes | Orange-brown |
| **Iapetus** | Two-toned (bright/dark) + craters | Mixed |

- Titan has the most complex texture: thick atmosphere, hydrocarbon features
- Each moon has its own procedurally generated texture
- Close-up viewing mode available from the moon selector
