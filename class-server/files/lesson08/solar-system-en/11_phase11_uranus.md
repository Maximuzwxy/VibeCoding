# Phase 11 — Uranus + Extreme Tilt + 5 Moons

## Goal
Implement Uranus, validating support for extreme axial tilt and ice giant appearance.

## Requirements

### Uranus Specifics
- Cyan-blue surface texture with faint atmospheric bands
- Ice giant appearance
- Axial tilt: 97.77° — nearly lying on its side
- Semi-transparent atmosphere as a child object

### Moons (5)
- **Miranda**: smallest, pale blue-grey
- **Ariel**: pale blue-grey
- **Umbriel**: darker grey
- **Titania**: largest
- **Oberon**: outermost
