# Solar System — 3D Interactive Exploration Platform

## Goal
A Three.js + Flask interactive 3D solar system platform with orbit rendering, celestial info display, bilingual support, online quizzes, and AI chat.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Three.js + CSS + JavaScript |
| Backend | Flask (Python) |
| LLM | DeepSeek V4 Flash |
| Database | JSON files |
