# Pong Game — 产品需求文档

## 1. 项目概述

### 1.1 项目名称
**Purr Pong** — 猫猫碰碰球

### 1.2 项目定位
一款画风可爱、手感流畅的经典 2D 弹球对战游戏。双人对战模式为主，兼具人机对战，适合休闲娱乐。

### 1.3 目标平台
桌面端浏览器（Chrome / Edge / Firefox），适配 16:9 屏幕。

## 2. 视觉效果与美术风格

### 2.1 整体风格
- **主题**：猫咪 + 甜品 + 柔和糖果色系
- **配色方案**（莫兰迪 + 马卡龙混搭）：

| 用途 | 颜色 | 色值 |
|------|------|------|
| 背景 | 暖奶油色 | `#fff8f0` |
| 场地底色 | 浅薄荷 | `#e8f5e9` |
| 玩家 1（左侧） | 草莓粉 | `#f8a4c8` |
| 玩家 2（右侧） | 蓝莓蓝 | `#a4c8f8` |
| 球 | 芒果黄 | `#ffcc80` |
| 中分线 | 浅灰粉 | `#e8d5d5` |
| 得分文字 | 暖棕 | `#6d5d4b` |
| UI 按钮 | 樱花粉 | `#f0c8d8` |
| 粒子特效 | 星星 / 爱心 | 随机马卡龙色 |

### 2.2 核心视觉元素
- **球拍**：猫爪造型（肉垫朝外），玩家 1 粉色爪，玩家 2 蓝色爪
- **球**：毛线球造型，带纹理细节，击中时短暂压扁变形
- **背景装饰**：柔和网格 + 漂浮小星星 / 奶油气泡
- **击中火花**：彩色小星星粒子爆发
- **得分庆祝**：得分方一侧短暂出现烟花

### 2.3 字体
- 标题与 UI：圆体 / 手写风格（如 `Comic Neue` / 系统圆体回退）
- 数字：圆润可爱风格

### 2.4 动画效果
- 球拍移动：轻微弹性缓冲（ease-out）
- 球碰撞：缩放弹跳 + 粒子爆发
- 得分：数字弹跳放大
- 胜利：全屏撒花 + 星星飘落
- 场边猫咪角色随得分做表情变化

## 3. 游戏功能

### 3.1 模式

#### 3.1.1 双人对战模式（默认）
- 玩家 1：`W` / `S` 控制左侧球拍上下移动
- 玩家 2：`↑` / `↓` 控制右侧球拍上下移动

#### 3.1.2 人机对战模式
- 玩家控制左侧球拍（`W` / `S`）
- AI 控制右侧球拍，具有三级难度：
  - **Easy**：AI 反应慢，偶尔失误
  - **Medium**：AI 追踪球，速度适中
  - **Hard**：AI 预判轨迹，速度快

### 3.2 游戏参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 场地尺寸 | 800 × 500 | Canvas 画布 |
| 球拍高度 | 80px | 猫爪球拍 |
| 球拍宽度 | 14px | |
| 球大小 | 16px | 毛线球直径 |
| 初始球速 | 4px/帧 | |
| 球速递增 | +0.15/次 | 每次击中球拍加速 |
| 最大球速 | 9px/帧 | |
| 获胜分数 | 7 分 | 先到 7 分者胜 |

### 3.3 物理规则
- 球碰上下墙壁反弹，角度对称
- 球碰球拍时，根据击中位置偏移反弹角度：
  - 击中球拍中心 → 水平反弹（0°）
  - 击中球拍上部 → 向上反弹（最大 +45°）
  - 击中球拍下部 → 向下反弹（最大 -45°）
- 球出左边界 → 玩家 2 得分
- 球出右边界 → 玩家 1 得分

### 3.4 游戏流程

```
[启动页面]
  ├── 选择模式：双人对战 / 人机对战
  │     └── 人机对战 → 选择难度 Easy / Medium / Hard
  ├── [3-2-1 倒计时]
  │     └── 倒计时动画，每拍放大缩小
  ├── [游戏进行中]
  │     ├── 暂停（Space 键）→ 画面模糊 + 继续/退出按钮
  │     ├── 得分 → 庆祝效果 → 自动发球（1.5s 间隔）
  │     └── 到达 7 分 → 进入结算
  └── [结算页面]
        ├── 胜利方猫猫动画（跳跃撒花）
        ├── 显示比分、用时
        ├── [再来一局] → 重置比分，回启动页 / 直接开始
        └── [返回主菜单] → 启动页
```

## 6. 技术方案

### 6.1 文件结构（遵循项目规则）
```
Pong Game/
├── index.html   — HTML 结构（Canvas + UI 遮罩层）
├── style.css    — 全部样式
├── script.js    — 游戏逻辑
└── PRD.md       — 本文档
```

### 6.2 技术选型
- **渲染**：Canvas 2D API
- **游戏循环**：`requestAnimationFrame`
- **输入**：`keydown` / `keyup` 事件监听
- **物理**：自实现碰撞检测 + 反弹角度计算
- **状态管理**：游戏状态机（MENU / COUNTDOWN / PLAYING / PAUSED / GAMEOVER）

### 6.3 状态机
```
MENU → COUNTDOWN → PLAYING ⇄ PAUSED
                          ↓
                      GAMEOVER → MENU (or COUNTDOWN)
```

---

## 7. 非功能需求

- 帧率稳定在 60fps
- 输入响应延迟 < 50ms
- 双人操作互不冲突（W/S 与 ↑/↓ 独立）
- 球拍不得移出画布边界
- 窗口失焦时自动暂停
