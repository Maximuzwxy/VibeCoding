# Phase 6 — Venus + Cloud Layer + Retrograde Rotation

## Goal
Implement Venus, validating the framework's support for external cloud layers and retrograde (reverse) rotation.

## Requirements

### Venus Specifics
- Orange-yellow cloudy surface texture with atmospheric bands
- Thick external cloud shroud (semi-transparent sphere enveloping the planet)
- Cloud layer rotates independently from the surface
- Retrograde rotation: spins opposite direction to most planets
- Axial tilt: 177.4° (nearly upside down)
- No moons
